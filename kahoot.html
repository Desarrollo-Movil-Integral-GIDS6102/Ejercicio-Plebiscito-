🎮 Quiz Unity

Respuestas correctas con justificación detallada

1

¿Qué espacio de nombres se necesita para usar el nuevo Input System en un script?

▲ using UnityEngine.InputSystem;
◆ using UnityEngine.Input;
● using UnityEngine.InputActions;
■ using UnityEditor.InputSystem;
🔴 Rojo — Respuesta correcta
Para usar el nuevo Input System de Unity en un script C#, necesitás importar el namespace UnityEngine.InputSystem. Este es el espacio de nombres principal que contiene toda la API del paquete Input System, que reemplaza al antiguo Input Manager (UnityEngine.Input).
2

Se creó la acción "Move" de tipo Value y Control Type Vector2. ¿Cuál línea lee correctamente su valor?

▲ Vector2 mov = moveAction.action.ReadValue<Vector2>();
◆ Vector2 mov = moveAction.GetValue();
● Vector2 mov = moveAction.action.ReadValue<float>();
■ Vector2 mov = Input.GetAxis("Move");
🔴 Rojo — Respuesta correcta
Si la acción es de tipo Value con Control Type Vector2, el valor se lee con el método genérico ReadValue<Vector2>(). El tipo genérico debe coincidir exactamente con el Control Type definido en la acción. La opción con <float> fallaría por incompatibilidad de tipos, e Input.GetAxis() pertenece al sistema antiguo.
3

Si se suscribe un método con += en OnEnable(), conviene desuscribirlo con -= en OnDisable().

◆ Verdadero
▲ Falso
🔵 Azul — Verdadero
Es una buena práctica fundamental en Unity. Suscribirse con += en OnEnable() y desuscribirse con -= en OnDisable() evita fugas de memoria y errores por referencias "fantasma" (métodos que siguen escuchando eventos aunque el objeto esté inactivo o destruido). Ambos métodos son simétricos en el ciclo de vida del componente.
4

Un objeto 2D con Rigidbody (3D) interactúa normalmente con colliders Collider2D.

▲ Falso
◆ Verdadero
🔴 Rojo — Falso
En Unity, los sistemas 2D y 3D están completamente separados. Un Rigidbody (3D) solo detecta colisiones con colisionadores 3D, y un Collider2D solo interactúa con otros componentes 2D. Para que interactúen correctamente, ambos objetos deben usar Rigidbody2D + Collider2D.
5

¿Cuál es la mejor forma de enviar la velocidad al Animator para alternar entre Idle y Caminar?

▲ animator.SetBool("Speed", movimiento);
◆ animator.Play(movimiento.x);
● animator.SetFloat("Speed", Mathf.Abs(movimiento.x));
■ animator.SetTrigger("Speed", movimiento.x);
🟡 Amarillo — Respuesta correcta
La forma estándar es usar un parámetro Float llamado "Speed". Mathf.Abs() garantiza un valor positivo sin importar la dirección (izquierda/derecha), permitiendo transiciones fluidas: Idle cuando Speed ≈ 0 y Caminar cuando Speed > umbral. Además, SetTrigger no recibe ese tipo de argumentos.
6

Un Rigidbody2D con Body Type Kinematic no es afectado por la gravedad y se mueve mediante script.

◆ Verdadero
▲ Falso
🔵 Azul — Verdadero
Correcto. Un Rigidbody2D con Body Type = Kinematic: No le afecta la gravedad. No responde a fuerzas físicas como AddForce. Se mueve mediante script usando MovePosition(). Ideal para plataformas móviles o enemigos con rutas controladas.
7

En el Input Actions Asset, ¿qué configuración es la adecuada para la acción "Jump"?

▲ Action Type: Button
◆ Action Type: Value, Control Type: Vector2
● Action Type: Pass Through, Control Type: Axis
■ Action Type: Value, Control Type: Quaternion
🔴 Rojo — Action Type: Button
"Jump" es una entrada discreta/booleana (se presiona o no), por lo que corresponde Button. Las demás opciones no aplican: Value + Vector2 es para movimiento continuo, Axis para gatillos analógicos y Quaternion para rotaciones.
8

Un Prefab permite modificar un objeto una vez y que el cambio se aplique a todas sus copias.

◆ Verdadero
▲ Falso
🔵 Azul — Verdadero
Esa es la definición exacta de un Prefab. Es un template reutilizable que mantiene un vínculo con todas sus instancias: al modificar el Prefab original, el cambio se propaga automáticamente a todas las copias presentes en la escena.
